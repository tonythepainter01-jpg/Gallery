TONY THE PAINTER WEBSITE PACKAGE

Files included:
- index.html: Main website page
- gallery.html: Gallery page
- styles.css: Website styling
- script.js: Form warning if email has not been configured
- assets/tony-flyer.png: Main flyer image

IMPORTANT FORM SETUP:
Open index.html and replace every instance of:
YOUR-EMAIL-HERE
with the email address where quote requests and testimonial comments should be sent.

There are two forms:
1. Request Quote form
2. Customer Testimonials form

Because this is a static website, testimonial comments do not automatically appear live on the page. They are emailed to Tony for review. To publish a real testimonial, copy the approved comment into the Customer Testimonials section in index.html.

GALLERY PHOTOS:
Place project photos in the assets folder. Make sure the image filenames in gallery.html exactly match the files in the assets folder.
Example: assets/3010.jpg

To test locally:
Open index.html in your browser.
